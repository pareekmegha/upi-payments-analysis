Definitions and caveats
  • Volume is transactions settled through NPCI's UPI system, in billions. Value is in ₹ lakh crore (1 lakh crore = ₹1 trillion). Average ticket is value divided by volume.
  • App shares divide each app's settled volume by total UPI volume. NPCI's own app table adds on-us transactions, which the headline total leaves out, so its figures run about 2% higher in 2021 to 2023.
  • Paytm Payments Bank (to January 2024) and Paytm (from February 2024) are separate legal entities. Here they are one line, because it is the same app.
  • The forecast for volume uses a damped-trend exponential smoothing model with monthly seasonality, trained on June 2021 onward. Ticket uses the same model without seasonality. Value is volume times ticket. Ranges come from simulation and treat volume and ticket errors as independent, so the value range is somewhat too narrow.
  • Only 65 months of post-COVID history exist, so forecasts beyond about six months are trend extrapolation, not predictions of particular months.
  • Figures for PhonePe and Google Pay value are missing at the source for February and March 2022, so app-level value is not shown.
